`HEARTLAB_1998_CDC_CHD_dataset.csv` is the configured dataset (50 states + DC; 1998 risk factors; 1998 CHD mortality, ICD-9 410.0–414.9, age-adjusted, ages 35+). It was assembled from separate CDC-published state tables and is **not** the textbook's original `CDCHeartRisk.xls`.

Uploads made through the interface are saved here as `uploaded_dataset.*`. HEARTLAB never writes synthetic test data into this folder.
